# PIXEL RANGE

마우스로 조준하고 로봇 표적을 맞히는 30초 아케이드 슈팅 게임입니다.

## 조작

- 마우스로 조준하고 클릭해서 사격
- `R` 키 또는 재장전 버튼으로 탄창 교체
- 황금 로봇은 추가 점수

`index.html` 하나로 실행되는 정적 웹 게임입니다.

## GitHub Pages로 무료 공개하기

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 `https://kimhyoje.github.io/hit/`에서 플레이할 수 있습니다.

첫 배포에는 몇 분이 걸릴 수 있습니다.
